# MANUAL_TESTS — ручные проверки

Чеклист для локальной проверки перед checkpoint / deploy.  
Автотесты: `npm test` (225 тестов) — обязательны, но не заменяют UI.

---

## 0. Подготовка

- [ ] `npm install` и `npm install --prefix backend` выполнены
- [ ] `backend/.env` настроен (`PORT=3001`, `DATABASE_PATH`, `ADMIN_KEY`, `CORS_ORIGIN`)
- [ ] Локальная БД на месте (`backend/data/daogreen.db`) — не пустая seed-БД
- [ ] `npm test` — все тесты зелёные

## 3. Планировщик — стены

Путь: проект / standalone plan → слой «Помещение» или «Перегородки» → инструмент «Стена».

### Рисование

- [ ] Первая точка ставится, цепочка продолжается
- [ ] Enter / двойной клик на старт — завершение цепочки
- [ ] Esc — отмена черновика
- [ ] Backspace — удаление последней точки

### Замыкание помещения (WALL-BUGFIX-001)

- [ ] Нарисовать прямоугольник: A → B → C → D
- [ ] Финальный клик с snap на точку A
- [ ] Появляется закрывающий сегмент D→A, **нет разрыва**
- [ ] Черновик завершается, стены в плане как 4 рёбра (network)

### Выбор и редактирование

- [ ] Клик по **телу** стены (закрашенная область) — стена выделяется
- [ ] Клик по кайме / оси — тоже работает
- [ ] Узлы стены перетаскиваются
- [ ] Оранжевая подсветка совпадает с телом стены

### Nudge (стрелки на выбранной стене)

- [ ] Кнопки ↑↓←→ сдвигают стену на **10 мм** (или `display.arrowStepMm`)
- [ ] Соседние стены остаются соединёнными в общих узлах
- [ ] Клавиши-стрелки (если включены) — то же поведение

### Erase

- [ ] Инструмент ластика удаляет стену по клику на тело

## 4. Планировщик — размеры

- [ ] У прямоугольного помещения **нет двух одинаковых** горизонтальных размеров на один пролёт
- [ ] Нет паразитных подписей ~49 мм у углов (артефакт толщины)
- [ ] Реальные короткие стены ≥100 мм показывают размер
- [ ] Размеры комнаты (ширина/высота/площадь) не мешают клику по стене
- [ ] WallSnapIndicator, WallAngleLabels, WallLiveChips работают при рисовании стены
